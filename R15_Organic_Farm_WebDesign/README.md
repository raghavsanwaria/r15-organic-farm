## Project files
- `index.html` — responsive home page and enquiry form
- `products.html` — product catalogue and sample price table
- `assets/style.css` — custom styling, two responsive media queries and transitions
- `assets/script.js` — searchable catalogue, cart, validation and Local Storage

## Run locally
Open `index.html` in a modern browser. Bootstrap CSS/JS is loaded from jsDelivr CDN, so an internet connection is required for Bootstrap styling and the responsive navigation/cart panel.

## Important demo limitations
- Product prices are illustrative only. Confirm real prices and units with the business before publication.
- The enquiry form validates input in the browser but does not transmit it to a server.
- The cart is a front-end demonstration. It does not take payment or create a real order.
- This static GitHub Pages project does not process or retain personal information on a server.

## GitHub Pages deployment
1. Create a GitHub account and a new public repository, for example `r15-organic-farm`.
2. Upload all project files, preserving the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear. Test both `index.html` and `products.html` on phone and desktop.
